数据与工程说明

这些页面不仅展示结果，也说明结果如何产生。每个模块都区分数据属性、处理链路、验证方法、技术栈与演示边界，让指标口径可以追溯、分析过程可以解释、Demo 能力与生产系统之间的差距可以被清楚识别。

01 · PROVENANCE数据有出处

真实、模拟与混合数据分别标注，不把演示样本包装成生产数据。

02 · METHOD指标有口径

从原始粒度、清洗映射到聚合与归因，说明关键转换和假设。

03 · VALIDATION结论有边界

使用结构校验、业务不变量和回归锚点，同时披露静态快照限制。

MODULE 01

多因子研究

从本地行情与财务归档开始，构建可重复执行的 A 股因子研究流水线，并把点时数据、18 个因子、6 类风格、诊断和组合回测组织为可查询的数据模型与静态研究快照。

真实市场数据 · 静态快照
  1. TDX / tqcenter / 指数源
  2. CSV ETL / PostgreSQL
  3. 因子计算 / 预处理 / 中性化
  4. 诊断 / 回测 / 展示快照

数据来源

  • 通达信日线与财务归档文件；tqcenter 提供证券信息、股本与分红等补充数据。
  • 本地基准指数种子及 AkShare 补充数据。
  • 财务指标定义表与版本化因子目录作为计算元数据。

处理链路

  • Python 将原始文件解析为维表、事实表与桥表 CSV，再装载 PostgreSQL 星型模型。
  • 月度股票池与财务桥表采用 point-in-time 口径，降低前视偏差。
  • 因子按方向对齐、MAD×3 缩尾、Z-score 标准化，并对市值与行业做截面中性化。

验证方法

  • CSV 表头预检、主外键与 CHECK 约束、行数及业务不变量校验。
  • 跟踪覆盖率、Spearman Rank IC、1/3/6 月前瞻收益和因子相关性。
  • 组合与风格回测独立生成快照，流水线任一阶段失败即停止。

技术栈

Python 3.13pandasNumPyPostgreSQLPowerShellTableau PublicGoogle SheetsHTML / CSS / JS

演示边界

  • 网页消费生成后的静态 JS/CSV 快照，不在浏览器中运行全量因子流水线，也不是实时行情终端。
  • 组合回测未计交易费、滑点、税费与市场冲击；历史 ST 仅能按当前名称近似识别。
  • 外部 Tableau 视图依赖网络可用性；研究结果仅用于方法展示，不构成投资建议。

MODULE 02

财富管理

用可解释的规则原型串联总行资产配置、客群机会、单客户诊断、产品适配、受控解读与智能体治理，重点展示业务流程、合规约束和反馈闭环，而不是伪装成已接入的生产系统。

合成业务数据 · 规则原型
  1. 模拟客户 / 产品 / 行为
  2. 画像与配置缺口
  3. 适当性硬约束 / 匹配评分
  4. 受控解读 / 反馈 / 治理

数据来源

  • 客户、产品、持仓、反馈和治理指标均为前端合成演示数据，不含真实客户或银行数据。
  • 配置缺口与治理趋势由离线脚本生成展示快照；策略页嵌入个人 Tableau Public 作品。
  • 产品说明书字段以受控演示摘要呈现，用于展示引用与风险揭示方式。

处理链路

  • 根据 KYC、风险等级、期限、流动性、集中度与历史反馈构建客户画像。
  • 先执行适当性硬拦截，再计算配置缺口、产品匹配理由、风险提示与建议金额。
  • 受控知识摘要与客户变量进入模板，经必含句式与禁止词扫描，并附人工复核状态后展示。

验证方法

  • 页面展示逐条规则轨迹、拦截原因、引用来源、版本号和复核状态。
  • 通过反馈回流、采纳率、引用率、人工复核率与阻断数量展示治理闭环。
  • 生产化接口边界在文档中显式列出，便于替换为客户、产品和反馈 API。

技术栈

HTML5CSS GridVanilla JavaScriptSVGTableau Public静态快照规则引擎原型

演示边界

  • 当前没有接入真实 CRM、交易系统、后端 API 或生成式模型；页面中的“AI”内容是可审计的规则与模板原型。
  • 静态发布包不包含展示快照的上游生成项目，当前数据不应被理解为可在本仓库独立刷新。
  • 所有建议仅用于流程演示，实际客户触达仍需完成 KYC、适当性确认与人工复核。

MODULE 03

数据分析

将 Streamlit 零售经营看板迁移为可静态托管的交互式前端，通过只读导出器固化语义层，覆盖渠道、客户、产品、竞品、营销、留存与行动闭环。

市场/产品数据 + 模拟经营数据
  1. DuckDB / PBI CSV
  2. SQL 聚合 / pandas 清洗
  3. 版本化 data.js 快照
  4. 7 个经营工作区 / 月报

数据来源

  • 导出器以只读方式读取相邻项目的 DuckDB 语义层和 Power BI 展示 CSV。
  • 多数净值来自 AkShare；源库的产品与季度规模口径标记为 iFinD，展示快照按产品和季度聚合；AMAC 排名来自基金业协会。
  • ETF 使用前复权收盘价代理，3 只货币基金及部分字段按标记为模拟；客户交易、持仓、迁移、留存与营销行为均为模拟数据。
  • 快照记录 schema_version、生成时间与最新业务快照日。

处理链路

  • SQL 统一产品、渠道、客户与时间粒度，pandas/NumPy 完成拼接、缺失值处理、分层与滚动指标。
  • 聚合 AUM、申赎、净值影响、渠道效率、客户迁移、留存、活动转化与预警案例。
  • 仅将分析所需语义快照导出为 data.js，浏览器不加载 DuckDB 或原始交易明细。

验证方法

  • Node 冒烟测试覆盖 7 个工作区、核心二级页签、产品切片、预警下钻与移动端结构和交互。
  • 对 AUM、净申购、客户数、预警、迁移和活动等关键业务数值设置回归锚点。
  • 渠道采用颜色与形状双重编码并配显式图例；客户编号默认掩码。

技术栈

PythonDuckDBSQLpandasNumPyHTML / CSS / JSInline SVGlocalStorageNode.js Smoke Tests

演示边界

  • 处置状态、Owner 与备注只保存在当前浏览器 localStorage，不写回源库，也不跨设备同步。
  • 预警日志是 50 条精选历史案例，并非七条规则的全量扫描；营销情景校准不代表因果增量或真实 ROI。
  • 月报在浏览器端按当前切片生成 Markdown；竞品为精选样本，不能解释为全市场份额或行业分位。

Engineering discipline

严谨性如何落实到 Demo

01数据属性显式标注

市场/产品数据、模拟业务数据与混合快照采用不同标签，不混淆可信范围。

02计算口径可回溯

保留源表、粒度、时间窗口、公式和版本信息，关键指标可定位到处理链路。

03验证不是装饰

结构约束、业务不变量、数值锚点、诊断统计与页面冒烟测试共同覆盖。

04隐私与发布隔离

源数据库与凭据不进入浏览器；快照仅发布展示所需字段，客户标识在界面掩码且当前客户数据均为模拟。

Scope & limitations

统一披露

  • 所有页面均为研究与产品原型展示，不构成投资建议、销售承诺或生产系统输出。
  • 静态快照反映生成时点的数据与口径，不代表实时状态；外部数据源与 Tableau Public 可能受网络可用性影响。
  • 客户相关数据均为模拟，标识默认掩码；生产应用仍需权限控制、审计、数据质量 SLA 与合规审批。
  • 页面同时说明已实现能力与生产化缺口，避免把可交互 Demo 等同于已上线系统。
